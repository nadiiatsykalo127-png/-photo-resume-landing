# NadinArtDigital — AI для кар’єри

Єдиний застосунок для кар’єрного напряму NadinArtDigital:

- `/career` — оригінальний синій лендинг;
- `/career/photo` — 3 прев’ю з водяним знаком, вибір одного, оплата 49 грн, одноразове завантаження чистого фото;
- `/career/resume` — три безкоштовні профілі резюме, редагування, AI-підказки, PDF і DOC;
- `/` — тимчасово перенаправляє на `/career`, доки головна екосистеми не готова.

## Локальний запуск

```bash
npm install
cp .env.example .env
npm start
```

Без секретів працюють лендинг і конструктор резюме. Для генерації фото та AI-підказок потрібен `GEMINI_API_KEY`; для автоматичної оплати — production `MONO_X_TOKEN`.

Секрети додаються тільки в налаштуваннях Render і ніколи не зберігаються в GitHub. Конфігурація `render.yaml` фіксує регіон Frankfurt та власний домен.

## Безпека оплати

Чисті фото залишаються на сервері. Браузер отримує лише прев’ю з фізично нанесеним водяним знаком. Після вибору сервер створює окремий рахунок Monobank на 49 грн; webhook перевіряється ECDSA-підписом. Завантаження відкривається лише після статусу `success` і є одноразовим.

У Render для приватних оригіналів і стану замовлень підключається постійний диск `/var/data`. Для першого запуску з одним сервером цього достатньо; під час подальшого масштабування сховище можна винести в окремий приватний object storage і базу даних.
